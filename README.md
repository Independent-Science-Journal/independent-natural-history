# 私設博物誌
Independent Natural History

「蒐め、観察し、調べ、つくる。」

個人が運営する、科学・自然史・歴史資料などの
公開アーカイブです。

## サイト
https://independent-science-journal.github.io/independent-natural-history/

## 主な内容

- 蒐集：鉱物、古書、歴史資料など
- 記録：実験、調査、観察、計算など
- 装置：自作した装置の設計・製作記録
- 写真帖：天体、鉱物、自然などの写真
- おみやげ：個人制作物の紹介・頒布

## ファイル構成

- index.html：トップページ
- style.css：サイト全体の共通デザイン
- app.js：トップページの動作
- data.js：データ管理用（整備予定）
- css/：ページ別のデザイン
- js/：JavaScript用フォルダ
- collections/：蒐集ページ
- records/：記録・研究記事
- instruments/：装置ページ
- gallery/：写真帖
- images/：画像
- videos/：動画

## 管理方針

1. 各ページのHTMLは該当する分類フォルダに置く。
2. 共通デザインはstyle.cssで管理する。
3. ページ固有のデザインはcss/で管理する。
4. JavaScriptは将来的にjs/へ整理する。
5. 画像・動画は記事や用途ごとに分類する。
6. 公開前にページ表示とリンクを確認する。

## 公開方針

資料の閲覧は原則無料です。
データや制作過程についても、
可能な範囲で公開します。

掲載資料の再利用条件は各資料の表示に従います。

本サイトは個人による独立した活動です。
